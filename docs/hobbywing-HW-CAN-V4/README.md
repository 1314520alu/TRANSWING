# 好盈 H150 / HW-CAN V4 电调配置说明

**文档版本**：2026-09-22  
**电调**：Hobbywing（好盈）H150，HW-CAN V4 配置工具  
**用途**：批量写入 NodeID、油门通道、CAN 油门、灯色与转向  
**配套文件**：

| 文件 | 用途 |
|------|------|
| `HW-CAN_V4配置文件-12轴-CAN优先.xls` | 通用 1–12 电机，仅下发 ID/通道 + CAN 油门 |
| `HW-CAN_V4配置文件-OctaQuad共轴八旋翼.xls` | 共轴八旋翼 OctaQuad X，含灯色/方向 |

---

## 1. 使用前注意

1. 用好盈 **HW-CAN V4** 上位机打开对应 `.xls`，按工作表逐台连接电调后写入。
2. **使能=1** 的行才会下发；未使能项不会改电调内原有值。
3. 以 **HEX / 配置数值** 为准；若描述与数值冲突，以数值为准。
4. 总线默认按 **500 kHz** CAN 设计（表内总线速率项默认未使能，按现场总线已对齐即可）。
5. 写入 NodeID 后需按新 ID 重新寻址；建议单台逐个配置，避免总线冲突。

### 关键数值约定（与模板 HEX 对齐）

| 项目 | 值 | 含义 |
|------|----|------|
| 油门方式 | `0` | **CAN 油门**（本仓库默认，CAN 优先） |
| 油门方式 | `1` | PWM 油门 |
| 方向 | `0` | 顺时针 CW |
| 方向 | `1` | 逆时针 CCW |
| 灯色 | `2` | 绿灯 |
| 灯色 | `4` | 红灯 |
| 闪烁 | `255` | 不闪烁 |
| 闪烁 | `2` | **2 Hz 闪烁** |

NodeID 与寻址字节关系：`addr = 0x80 | NodeID`（例如 ID=65 → `0xC1`）。

## 2. 通用 12 轴表（CAN 优先）

**文件**：`HW-CAN_V4配置文件-12轴-CAN优先.xls`

### 2.1 使能项

每台电机（工作表 `1`–`12`）默认只使能：

- **设置 ID**：写入 NodeID + 油门通道  
- **油门方式**：`0` = CAN 油门  

方向、灯色、MSG 帧率、定位、有刷、IMU 等默认 **不使能**，可按需打开。

### 2.2 NodeID / 通道分配

| 电机 | NodeID | 油门通道 |
|------|--------|----------|
| 1 | 65 | 1 |
| 2 | 70 | 2 |
| 3 | 75 | 3 |
| 4 | 80 | 4 |
| 5 | 85 | 5 |
| 6 | 90 | 6 |
| 7 | 95 | 7 |
| 8 | 100 | 8 |
| 9 | 105 | 9 |
| 10 | 110 | 10 |
| 11 | 115 | 11 |
| 12 | 120 | 12 |

规则：`NodeID = 60 + 5 × 电机号`，通道 = 电机号。

另含参考模板页：`CAN油门-CW`、`PWM油门-CW`。

## 3. 共轴八旋翼 OctaQuad 表

**文件**：`HW-CAN_V4配置文件-OctaQuad共轴八旋翼.xls`  
**飞控构型**：ArduPilot `FRAME_CLASS = 4`（OctaQuad），`FRAME_TYPE = 1`（X）  
**混控依据**：`AP_MotorsMatrix::setup_octaquad_matrix(MOTOR_FRAME_TYPE_X)`

### 3.1 使能项（每台均开启）

1. 设置 ID（NodeID + 油门通道）  
2. 油门方式 = CAN  
3. 设置灯色（前红 / 后绿，2 Hz）  
4. 设置方向（与 ArduPilot X 共轴混控一致）

### 3.2 电机布局（俯视，机头向前）

```
              前
     M2/M5         M1/M6     ← 红灯 2Hz（上/下共轴）
        \           /
         \         /
          \       /
           \     /
            \   /
            /   \
           /     \
          /       \
         /         \
        /           \
     M3/M8         M4/M7     ← 绿灯 2Hz（上/下共轴）
              后
```

- **前**：电机 1、2、5、6 → **红灯**，2 Hz 闪烁  
- **后**：电机 3、4、7、8 → **绿灯**，2 Hz 闪烁  
- 同臂上下共轴：M1↔M6，M2↔M5，M3↔M8，M4↔M7  

### 3.3 参数总表

| 电机 | 位置 | NodeID | 通道 | 方向 | 灯色 | 闪烁 | 油门 |
|------|------|--------|------|------|------|------|------|
| 1 | 前右上 FR-Top | 65 | 1 | CCW | 红 | 2 Hz | CAN |
| 2 | 前左上 FL-Top | 70 | 2 | CW | 红 | 2 Hz | CAN |
| 3 | 后左上 RL-Top | 75 | 3 | CCW | 绿 | 2 Hz | CAN |
| 4 | 后右上 RR-Top | 80 | 4 | CW | 绿 | 2 Hz | CAN |
| 5 | 前左下 FL-Bot | 85 | 5 | CCW | 红 | 2 Hz | CAN |
| 6 | 前右下 FR-Bot | 90 | 6 | CW | 红 | 2 Hz | CAN |
| 7 | 后右下 RR-Bot | 95 | 7 | CCW | 绿 | 2 Hz | CAN |
| 8 | 后左下 RL-Bot | 100 | 8 | CW | 绿 | 2 Hz | CAN |

工作表命名示例：`1-前红`、`3-后绿`；另有 `说明`、`总览` 页。

### 3.4 飞控侧建议

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `FRAME_CLASS` | 4 | OctaQuad |
| `FRAME_TYPE` | 1 | X |
| CAN 电调驱动 | 与 NodeID/通道表一致 | 通道 1–8 对应电机 1–8 |

若机架为 Plus / H / CW_X，方向表需按对应 `setup_octaquad_matrix` 分支重做，不能直接套用本 X 表。

## 4. 推荐配置流程

1. 单台上电，确认当前 CAN 可联（出厂或旧 ID）。  
2. 打开对应电机工作表，确认使能项与 NodeID/通道无冲突。  
3. 先写 **设置 ID**，再按新 ID 写 **油门方式 / 灯色 / 方向**。  
4. 八台全部写完后，上总线检查：前红后绿、2 Hz 闪烁、ID 无重复。  
5. 飞控解锁前做电机顺序测试（Mission Planner Motor Test），核对转向与桨向。
